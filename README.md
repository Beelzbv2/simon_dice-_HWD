# simon_dice-_HWD
Pensamiento Personal:
Se crea este readme para la primera tarea de HWD. tomando en cuenta que seria mi primera vez manejando este tipo de proyecto en un lenguaje que no sea python no me tengo mucha fe pero que sea lo que el dios maquina sea(tremenda referencia a Warhammer 40.000).

Informacion:
Simon dice es un juego rapido de memoria y mecanizacion simple que se ha jugado y creado hace bastante tiempo, mas abajo encontraran los detalles de piezas para poder crealo ustedes mismos.

Piezas a ocupar para este trabajo:
3 pulsadores (Pulsadores de contactomomentáneo (4 pines o 2 pines tipoSPST))
3 diodos LED ( 5 mm de colores distintos(ej. Rojo, Verde, Azul o Amarillo)) 
3 Resistencias de 220 (220 Ω (1/4W, 5% de tolerancia))
1 zumbador (Buzzer pasivo de 5V)
1 placa microcontrolador (Arduino UNO R3)
1 Protoboard / Breadboard (Placa de pruebas estándar)
varios Cables de Conexión (Jumpers macho-macho / machohembra)
